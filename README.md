# daniela-valerio.github.io

Personal academic website of Daniela Valerio, live at **https://daniela-valerio.github.io**.

## Files

| File | What it is | How to update |
|---|---|---|
| `index.html` | Home page: bio, working papers, email | Click the file, then the pencil icon; edit the text and commit |
| `cv.html` | CV page (the "CV" tab): shows the PDF with a download link | Usually no changes needed |
| `style.css` | Design (fonts, colors, layout) | Usually no changes needed |
| `files/Valerio_CV.pdf` | The CV | Export from Overleaf, name it exactly `Valerio_CV.pdf`, upload into `files/` (replaces the old one) |
| `files/img/photo.jpg` | Portrait (shown in black and white) | Upload a new `photo.jpg` into `files/img/` |

Changes appear on the site a minute or two after each commit. Reload with Cmd + Shift + R to see them.
